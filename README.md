# 曹仁超學習庫｜2007–2010

繁體中文（香港）私人學習整理。收錄博客公開資料源嘅 476 篇文章目錄、原創主題短摘要，以及 7 章 21 課。

- 2007 年：108 篇
- 2008 年：274 篇
- 2009 年：58 篇
- 2010 年：36 篇

## 使用

網頁：[開啟學習庫](https://nottsaifuture.github.io/-/)

離線：[下載學習包](Chao_Investment_Study.zip)，解壓後開啟 `study_and_catalogue.html`。摘要、課程及搜尋可離線使用，閱讀原文需要網絡。

每篇主題短摘要按標題與選讀段落整理，唔係逐行全文分析。學習庫唔包含原文全文；如果博客刪文，原文連結可能失效，已下載嘅摘要與課程仍然可用。

## 真實案例

21 課各附一個 2023–2026 真實案例練習：事件日期、已披露事實、課堂解讀、判斷題、答案解析及來源連結。部分事件以不同角度重用，唔代表涵蓋所有市場事件。

[搜尋案例](https://nottsaifuture.github.io/-/#cases)｜[下載案例筆記](lesson_cases_zh_hk.txt)

資料核對日：2026-10-05。近年案例係新增教學內容，唔係曹仁超對近年事件嘅評論。已發生數據、當時預測同假設計算分開標示；並非即時市場資訊或回報保證。

## 閱讀與資料

先睇第七章嘅跨年份比較，再按需要讀揀股、趨勢、止蝕及驗證課。可按年份、主題、標題及摘要搜尋。

原始資料：[曹仁超投資者筆記博客](https://chaozmarket.blogspot.com/)，刊登者顯示為 JoeJai。補充知識同訪談／轉載評論另有標示。刊登日期可能同內文日期不同。

課堂係原創教學整理，唔係官方作者網站。未有策略回測或驗證交易回報。

閱讀進度與收藏只保存在目前瀏覽器，唔會同步。來源範圍與限制見 `coverage.json`。
